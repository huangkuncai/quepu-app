## 仍保持关闭或演示态

- 用户已确认采用参考 APK 的宿松麻将规则；开房档位、胡型/花数边界和部分结算规则已形成 `8931-apk-baseline.1`。原裁判位于参考 App 服务端，仍缺失的叠加公式和动作优先级保持 draft，牌桌不展示伪造结算。
- 俱乐部申请、审批、成员/RBAC、楼层发布尚未连接生产 API；当前数据明确标记“开发演示”。
- 钻石余额、冻结、扣除与后台调账尚未连接生产账本；客户端没有充值入口。
- 战绩列表、单局/总结算详情依赖正式结算与历史 API，目前只提供安全空状态。
- iOS 仍需在可用签名/设备环境完成归档与真机验收。
