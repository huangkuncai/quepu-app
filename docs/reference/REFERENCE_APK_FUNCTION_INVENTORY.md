## 1. 基本信息

- 应用 ID：`cn.com.kypj.XSSSPlatform`
- 应用名：宿松
- 版本：`1.0 (1)`
- Android SDK：最低 16，目标 31
- 引擎：Cocos2d-x + Lua，业务主体为编译后的 `.luac`
- 方向：启动页横屏，主游戏界面为传感器横屏

## 2. 可借鉴的产品结构

### 2.1 大厅

- 顶部用户头像、昵称、ID 和钻石余额
- 公告/活动轮播位
- 亲友圈主入口
- 创建房间和加入房间两个高频操作
- 战绩、玩法、反馈/客服、设置和退出
- 分享入口（我们只在合规审查后再接入）

### 2.2 俱乐部（亲友圈）

- 圈主信息、亲友圈 ID、当前玩法摘要和在线人数
- 按“楼层/包厢”切换规则组
- 每层显示多个可进入桌台，桌台可表达空闲、等待、进行中等状态
- 快速开始，自动寻找可加入房间
- 游戏管理、房卡/消耗统计、战绩、成员、消息和活动
- 创建/加入俱乐部、入圈设置、申请处理、成员管理
- 房间规则详情、备注、换房、成员查看和俱乐部聊天

### 2.3 房间与对局通用能力

- 创建房间、输入房号加入、规则详情
- 等待房、选座/准备、开始、游戏中和结算状态
- 解散房间申请和投票
- 用户信息、玩家备注、局内聊天、快捷语、表情和语音
- 距离/定位提示，用于面对面同桌风险提示
- 局结算、总结算、战绩详情和分享
- 网络等待、重连和消息提示

### 2.4 游戏模块

从资源和模块名可确认：

- 宿松麻将（`ssmj`）
- 斗地主（`landlords`）
- 掼蛋类模块（`gdjd`、`gdttz`，具体地方变体名需业务确认）
- 十三水类模块（`ssts`、`sstx`，具体规则需业务确认）
- 公共麻将手牌/打牌框架（`mjgame`）
- 公共扑克牌框架（`cardgame`）
- 比赛、排名、赛事记录模块（`match`）

## 4. 明确不借鉴的能力

根据当前产品约束，以下功能不进入客户端：

- 充值、支付、微信支付、兑换、提现或现金兑换
- 客户端钻石购买入口
- 金币房、商城、商品列表、兑换任务和奖励邮件
- 未经审核的比赛/排名/营销活动
- 无必要的通讯录读写、后台定位、后台录音、悬浮窗、系统设置修改和日志读取权限

## 5. 对我们的实现映射

### P0：第一版必须有

1. 横屏登录和大厅：用户信息、钻石余额只读、客服、设置。
2. 创建/加入房间：房号、玩法摘要、房间状态。
3. 亲友圈申请、审批、成员和管理员权限。
4. 楼层/包厢规则组和桌台列表。
5. 宿松麻将等待房、四方牌桌、准备、回合、断线重连和积分结算。
6. 战绩列表与单局/总结算详情。
7. 纯文本客服工单，不做客户端支付入口。

### P1：首版稳定后

- 局内快捷语和表情
- 亲友圈消息/公告
- 桌台快速匹配与换房
- 解散投票
- 战绩图片分享
- 可选的同桌距离风险提示，需最小权限和隐私审核

### P2：多玩法扩展

- 将通用房间壳、牌局状态机、结算、重连和回放抽象为共享能力
- 通过游戏插件/规则包增加其他麻将、掼蛋、斗地主和其他扑克玩法
- 美术、音效和布局按游戏包独立管理，避免首包体积过大

## 6. 安全与兼容性结论

该 APK 不能作为我们的技术基线：

- 目标 SDK 老旧，且仅支持 32 位 `armeabi`
- 使用 Debug 证书签名
- 权限范围过大，多项权限与我们的第一版无关
- 单包携带大量声音和多游戏资源，不利于首包体积和按需更新
- 包含支付/兑换/商城线索，与本项目明确的无充值入口约束冲突

我们仅借鉴它的横屏信息架构、亲友圈桌台隐喻、通用房间壳和多游戏模块分层。
